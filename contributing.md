# Wkład w projekt / Contributing

## Polski

Dziękujemy za chęć udziału w projekcie! Przed dodaniem wpisu prosimy o zapoznanie się z poniższymi zasadami.

### Zasady dodawania narzędzi

- Dodawaj tylko narzędzia, które są **aktywnie utrzymywane** i **rzeczywiście użyteczne** w kontekście KSeF lub FA(3).
- Narzędzia darmowe i open source umieszczamy na początku każdej sekcji.
- Sprawdź, czy podany URL działa i czy narzędzie faktycznie obsługuje KSeF lub FA(3).
- Jeden wpis na PR — wraz z krótkim uzasadnieniem, dlaczego dane narzędzie powinno znaleźć się na liście.

### Format wpisu

```
- [Nazwa](URL) - Krótki opis (jedno zdanie). Informacja o cenie jeśli dotyczy.
```

- Separator między nazwą a opisem to ` - ` (spacja, myślnik, spacja) — **nie** em-dash (`—`).
- Opis zaczyna się wielką literą i kończy kropką.
- URL bez ukośnika na końcu.
- Na końcu opisu dodaj: `Darmowy.` / `Open source.` / `Freemium.` / `Płatny.`

### Przykład

```
- [MójWalidator](https://example.com) - Walidator faktur FA(3) działający po stronie klienta. Open source.
```

### Procedura

1. Rozwidlij (fork) to repozytorium.
2. Dodaj wpis w odpowiedniej sekcji README.md.
3. Otwórz Pull Request z opisem: czym jest narzędzie i dlaczego należy do listy.
4. Podaj kategorię, do której wpis powinien trafić.

### Zgłaszanie martwych linków

Jeśli znalazłeś niedziałający link, otwórz Issue z tytułem `[martwy link] Nazwa narzędzia`.

## English

Thank you for contributing! Please read these guidelines before submitting.

### Rules for adding tools

- Only add tools that are **actively maintained** and **genuinely useful** for KSeF or FA(3).
- Free and open-source tools go at the top of each section.
- Verify that the URL works and the tool actually supports KSeF or FA(3).
- One tool per PR, with a brief explanation of why it belongs on the list.

### Entry format

```
- [Name](URL) - Short description (one sentence). Pricing info if applicable.
```

- Separator between name and description is ` - ` (space-hyphen-space) — **not** an em-dash (`—`).
- Description starts with an uppercase letter and ends with a period.
- No trailing slash on URLs.
- Append pricing tag: `Free.` / `Open source.` / `Freemium.` / `Paid.`

### Reporting dead links

Open an Issue titled `[dead link] Tool Name`.
